## 1. Princípio

Não fazer download massivo do perfil.

> **Selecionar pouco, mas selecionar bem.**

Priorizar:
- pessoas em ação;
- aprendizagem real;
- interação;
- descoberta;
- tecnologia;
- comunidade;
- expressão;
- movimento;
- media com espaço negativo suficiente para composição editorial.

Evitar:
- posters quando existe foto/vídeo real do evento;
- imagens excessivamente posadas;
- screenshots com UI do Instagram;
- assets com baixa resolução quando existe alternativa melhor;
- múltiplas cópias quase idênticas;
- imagens com texto incorporado quando o mesmo momento existe em fotografia limpa.

# 14. Manifesto de ficheiros

`assets.csv` deve conter:

```text
asset_id
section
source_url
source_post_url
source_type
original_filename
local_filename
media_type
resolution
duration
orientation
desktop_use
mobile_use
priority
status
rights_status
notes
```

Estados sugeridos:
- CANDIDATE;
- SELECTED;
- REJECTED;
- DUPLICATE;
- NEEDS_REVIEW.

`rights_status`:
- PUBLIC_REFERENCE;
- NEEDS_AUTHORIZATION;
- OFFICIAL_ASSET;
- UNKNOWN.

# 16. Instruções de qualidade

Para cada asset:
- obter a maior resolução acessível;
- não fazer screenshot se o ficheiro puder ser descarregado;
- não recomprimir desnecessariamente;
- preservar vídeo original;
- preservar orientação;
- guardar URL/post de origem;
- não remover metadata necessária à rastreabilidade;
- não aplicar filtros/edição nesta fase.
