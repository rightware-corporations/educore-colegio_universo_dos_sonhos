# 7. Aplicação na landing COLUS

A landing COLUS termina com um Convite Final claro / Warm Paper.

Para essa composição, a variante escolhida para o master é:

> **DARK FOOTER**

Motivo composicional:

- cria uma fronteira terminal clara;
- separa o Convite Final do rodapé utilitário;
- preserva a identidade global EduCore/RIGHTWARE;
- não interfere com a linguagem visual COLUS das secções anteriores.

A variante Light continua válida como alternativa do produto.
