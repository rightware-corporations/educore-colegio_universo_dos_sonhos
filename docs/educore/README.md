# EduCore — Documentação de produto

Decisões reutilizáveis entre implementações **EduCore**, sem as confundir com documentação específica de uma escola.

## Atualmente

`arquitetura/` contém:

- estratégia de produto e deployment;
- arquitetura SaaS distribuída aplicada ao EduCore;
- Super Admin RIGHTWARE no contexto EduCore.

Quando uma decisão deixar de ser específica do EduCore e se tornar um padrão transversal da empresa, deve ser promovida para `docs/rightware/frameworks/`.
