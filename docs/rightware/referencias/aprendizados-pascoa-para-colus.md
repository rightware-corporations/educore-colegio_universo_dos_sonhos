# Aprendizados do Páscoa → COLUS

> **Estado:** REFERÊNCIA DE DESIGN / NÃO COPIAR VISUALMENTE  
> **Data:** 2026-10-01  
> **Objetivo:** identificar o que funcionou no Colégio Páscoa como método de construção de identidade digital e transformar isso em princípio reutilizável para o COLUS.

---

## 1. Conclusão principal

O Páscoa não deve ser usado como template visual do COLUS.

Mas ele demonstra uma ideia importante:

> **a identidade da escola pode ser traduzida para um sistema visual próprio, e não apenas aplicada como logotipo + cores.**

O valor do Páscoa está no método:

```text
MARCA
→ identificar formas, cores e ritmo
→ abstrair
→ reinterpretar
→ criar linguagem visual
→ aplicar a toda a experiência
```

É esse método que deve ser levado para o COLUS.

---

# 2. O que foi observado no Páscoa

No código e nas telas da landing existem vários elementos consistentes:

- paleta própria verde, vermelho e amarelo;
- grandes círculos/anéis usados como elementos gráficos;
- barras verticais inclinadas;
- recortes e cantos assimétricos;
- imagens com shapes diferentes;
- superfícies claras e profundas;
- tipografia de grande impacto;
- composição editorial;
- fotografia dominante;
- vídeo integrado;
- motion discreto;
- secções que alternam ritmo visual.

O resultado é que a página não parece simplesmente:

> “EduCore com o logo do Páscoa”.

Ela parece:

> **uma experiência digital desenhada para o Páscoa.**

---

# 3. O que NÃO copiar para o COLUS

Não copiar literalmente:

- anéis do Páscoa;
- barras verdes/amarelas;
- proporções específicas;
- cantos e máscaras exatamente iguais;
- paleta;
- composição do hero;
- ordem das secções;
- portal público;
- slogans;
- tratamento fotográfico;
- estrutura de CTA.

### Regra

> **Copiar o princípio, não a forma.**

---

# 4. O método certo que o Páscoa prova

## 4.1 A marca é matéria-prima

A marca não serve apenas para:

- cabeçalho;
- favicon;
- rodapé.

Ela pode informar:

- geometria;
- motion;
- espaçamento;
- cor;
- máscaras;
- ritmos;
- microinterações;
- loaders;
- splash;
- estados vazios;
- componentes.

---

## 4.2 O símbolo pode ser desmontado conceitualmente

No Páscoa, elementos visuais da marca foram transformados em:

- círculos;
- acentos;
- shapes;
- barras;
- cores;
- curvas.

Isso cria continuidade sem repetir o logo completo.

### Aplicação ao COLUS

O COLUS permite extrair:

- livro aberto;
- lâmpada/luz central;
- radiais;
- pontos;
- expansão;
- laranja;
- azul;
- ideia de conhecimento a irradiar.

---

# 5. O que significa “não repetir o símbolo literalmente”

Não significa:

> “não usar formas do logo”.

Significa:

> **não usar o logo completo como decoração repetida sem transformação.**

### Uso correto

```text
símbolo
→ abstração
→ sistema gráfico
```

### Uso fraco

```text
símbolo
→ copiar
→ colar em toda a interface
```

O Páscoa está mais próximo do primeiro caso.

---

# 6. Aprendizado sobre composição

O Páscoa mostra uma boa prática:

> **a identidade não vive num único componente.**

Ela aparece no:

- hero;
- cards;
- foto masks;
- secções;
- cores;
- CTA;
- vídeo;
- transições;
- rodapé.

No COLUS queremos a mesma consistência, mas com outra gramática visual.

---

# 7. Aprendizado sobre media

O Páscoa usa:

- fotografia grande;
- fotografia sobreposta;
- vídeo;
- cards com media;
- conteúdo institucional.

Isto mostra que a experiência ganha força quando a escola é apresentada através de **pessoas e contexto**, não apenas texto.

No COLUS devemos ir ainda mais longe:

- linguagem mais cinematográfica;
- hero com media dominante;
- fotoensaio;
- galerias editoriais;
- uso mais sofisticado de vídeo.

---

# 8. Aprendizado sobre motion

O Páscoa usa motion leve:

- reveal;
- hover;
- scale subtil;
- deslocamento.

Isto é adequado.

No COLUS podemos ampliar a linguagem de motion, mas mantendo controlo.

### COLUS

Motion deve derivar de:

- expansão;
- iluminação;
- radial;
- descoberta;
- abertura.

---

# 9. Aprendizado sobre portal público

O Páscoa integra o portal na landing.

Isto é uma decisão do Páscoa.

Para o COLUS, foi tomada outra decisão:

> **landing pública e portal interno serão experiências separadas.**

Portanto, não copiar:

- item “Portal” na navegação;
- CTA “Entrar no portal”;
- secção pública de apresentação do portal;
- links para login.

Isto não torna o Páscoa “errado”.

É uma escolha arquitetural e comercial diferente para o COLUS.

---

# 10. Diferença de linguagem entre Páscoa e COLUS

## Páscoa

Tende para:

- comunidade;
- transformação;
- verde;
- formas arredondadas;
- identidade calorosa;
- movimento escolar;
- cores fortes.

## COLUS

Direção proposta:

- futuro;
- descoberta;
- conhecimento;
- luz;
- tecnologia;
- humanidade;
- editorial premium;
- laranja + azul;
- radiais;
- fotografia cinematográfica.

---

# 11. Matriz: princípio vs execução

| Princípio aprendido no Páscoa | Aplicação no COLUS |
|---|---|
| marca gera formas | símbolo gera livro, luz, radiais e pontos |
| cores entram no sistema | laranja e azul com neutros fortes |
| media tem protagonismo | hero cinematográfico + fotoensaio |
| formas são reconhecíveis | devices derivados do símbolo COLUS |
| motion é discreto | motion de expansão/luz/descoberta |
| landing tem personalidade | COLUS deve parecer uma experiência própria |
| portal faz parte da landing Páscoa | COLUS mantém portal totalmente separado |
| identidade percorre toda a página | mesma regra, outra gramática |

---

# 12. Regra RIGHTWARE derivada

> **Cada implementação deve parecer desenhada a partir da identidade do cliente, não apenas configurada para o cliente.**

Isto não significa criar um produto incompatível a cada vez.

Significa separar:

```text
CORE / CONTRATOS / MÓDULOS
          ↓
EXPERIENCE PLANE
          ↓
IDENTIDADE PROFUNDAMENTE PERSONALIZADA
```

---

# 13. Aplicação imediata ao COLUS

Antes de desenhar o visual final:

1. separar o logo em níveis de uso;
2. definir símbolo isolado;
3. identificar brand devices;
4. definir geometria;
5. definir motion language;
6. definir paleta;
7. aplicar ao wireframe;
8. testar se a landing continua reconhecível mesmo sem o wordmark completo.

### Teste

> **Se removermos o nome COLUS de uma secção, ainda deve existir algo na linguagem visual que faça aquela experiência parecer COLUS.**

Esse é o nível de identidade que procuramos.
